# Ethereum 101

**Ethereum** is the foundational L1 blockchain for the entire EVM ecosystem.

## Why It Matters for Pixel Journey
- Settlement layer for high-value NFTs and pixel assets.
- Strongest developer community and standards (ERC-721, ERC-1155).

## Getting Started
- Wallets: MetaMask, Rabby
- Explorer: [etherscan.io](https://etherscan.io)
- Gas fees: Variable — use gas trackers.

## Pixel Journey Tips
- Bridge assets via official bridges.
- Consider L2s for lower costs.
