## 🛡️ General EVM Safety & Best Practices

- **Wallets**: Use reputable non-custodial wallets (MetaMask, Rabby, or hardware like Ledger). Never share seed phrases.
- **Gas Fees**: Always check current gas prices. Use L2s to save dramatically vs mainnet Ethereum.
- **Bridges**: Use official or audited bridges only. Double-check addresses. Start with small test transfers.
- **DYOR & Scams**: The EVM space has many opportunities — and many rugs/phish. Verify contracts, use reputable dApps, enable transaction simulation where possible.
- **Cross-Chain Mindset**: Treat every bridge as a potential point of risk. Understand the security model of each chain.
