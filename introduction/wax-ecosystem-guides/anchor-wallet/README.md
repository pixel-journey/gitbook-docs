# Anchor Wallet

**Anchor Wallet** is a powerful, secure, and popular desktop + mobile wallet for WAX (and other Antelope-based chains). Many advanced users and developers prefer it for its features and control.

It offers excellent security, easy dApp integration, and is a great alternative (or complement) to Cloud Wallet.

This section contains guides for getting started with Anchor on desktop and mobile.

**Sub-pages:**
- Anchor Website
- Anchor Mobile
- Anchor Desktop App

Anchor is especially useful if you want to manage multiple accounts, sign transactions easily, or use more advanced features while staying in full control of your keys.
