# Cloud Wallet (My Cloud Wallet) - 2026 Px Guide

**Overview**: Non-custodial passkey wallet for WAX. Mobile apps discontinued.

## Getting Started & Migration
1. Go to [mycloudwallet.com](https://www.mycloudwallet.com/)
2. Sign in with Google/Email.
3. Follow passkey setup.
4. Soft/Hard claim keys for full control (12-word mnemonic).
5. Transition to Anchor or PxWallet for advanced use.

## Key Features
- Resource management (CPU/NET/RAM)
- Staking (~10% APY)
- NFT bridge
- dApp connections

## PXJ Workflows
- Mint/Recycle Pixals directly.

## Safety & DYOR
- Backup mnemonic securely.
- Beware phishing.
