# Cloud Wallet

**Cloud Wallet** (also known as My Cloud Wallet) is one of the most popular and user-friendly wallets on WAX. It’s especially great for beginners because it works directly in your browser and requires no installation.

[https://www.mycloudwallet.com/](https://www.mycloudwallet.com/)

In the Pixel Journey, many explorers use Cloud Wallet for:

- Managing their Pixal PFPs and other NFTs
- Staking and claiming rewards
- Participating in drops, blends, and crafting
- Sending and receiving WAXP and assets

This section contains practical guides for setting up and using Cloud Wallet effectively and safely.

**Sub-pages in this section:**
- Creating a Cloud Wallet
- NFT Inventory
- WAX Social (Uncut)
- dApp Explorer
- Managing Wallet Resources
- Staking Rewards
- Claiming Account Keys
- Cloud Wallet Settings

Use these guides alongside the other WAX tools (Anchor Wallet, Neftyblocks, etc.) as you build your collection and participate in the economy. If you have any questions, our Discord community is always happy to help!
