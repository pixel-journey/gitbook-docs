# Creating Drops on NeftyDrops

NeftyDrops is Neftyblocks’ tool for launching NFT drops.

### Key Features
- Create timed or open drops
- Set whitelist / allowlist requirements
- Configure pricing and supply
- Integrate with blends and other mechanics

Drops are a great way to release new Pixal-related or themed collections in a controlled and engaging way.

Access the drop creation tools from the NB Creator / NeftyDrops section in your account. The interface is straightforward and includes helpful previews before launching.
