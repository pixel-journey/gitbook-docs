# Creating Blends on NeftyBlends

NeftyBlends lets you create advanced blending recipes on Neftyblocks.

### What You Can Do
- Define input NFTs and output results
- Set probabilities and multiple possible outcomes
- Create complex crafting systems (great for Pixel Recycling and evolution mechanics)
- Integrate with drops and staking

Blends are one of the most powerful tools for creating engaging, long-term utility for collections.

You can access blend creation from the NB Creator tools. Start simple and expand as your collection grows. Many Pixel Journey mechanics rely heavily on well-designed blends.
