# NB Creator

The **NB Creator** tools on Neftyblocks give collection owners and creators powerful features to launch drops, create blends, manage staking, run ads, and more.

This section covers the main creator tools available on the platform.

**Sub-pages in this section:**
- Collection/Nefty Staking Levels (perks and discounts)
- Managing your Collection
- Creating Drops on NeftyDrops
- Creating Blends on NeftyBlends

These tools are especially useful for Pixel Journey-related collections and any creators looking to build engaging experiences on WAX.

Access the Creator Hub from your Neftyblocks account to get started.
