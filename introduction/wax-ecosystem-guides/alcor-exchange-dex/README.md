## 🛡️ Safety, DYOR & Best Practices

- **Wallet First**: Always use a non-custodial wallet like Anchor. Never share private keys or seed phrases.
- **Leverage Caution**: Perps trading on Hyperliquid via Alcor is powerful but risky. Use low leverage when starting (e.g., 2-5x) and have a clear exit strategy.
- **Liquidity & Slippage**: Check pool depth before large swaps. Smaller trades = less slippage.
- **Fees**: Alcor is generally low-fee, but always review transaction costs on WAX (CPU/NET/RAM).
- **DYOR**: Markets move fast. Verify all information on official sources. Past performance is not indicative of future results.
- **Scam Awareness**: Only use the official Alcor site (alcor.exchange). Bookmark it. Beware of phishing sites.
