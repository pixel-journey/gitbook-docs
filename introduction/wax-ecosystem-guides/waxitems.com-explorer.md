# WaxItems.com Explorer & Tools Guide (2026)

**Overview**: A lightweight, fast NFT and asset explorer for the WAX blockchain. Great alternative or complement to main explorers during high traffic. Features portfolio tracking, quick searches, and item details.

## Getting Started
1. Visit [waxitems.com](https://waxitems.com/).
2. Connect your Cloud Wallet or Anchor Wallet.
3. Search by collection, asset ID, account, or template.

## Key Features
- Fast asset/NFT lookup.
- Portfolio overview and valuation insights.
- Transaction history.
- Community-driven tool with ongoing improvements.

## PXJ Integration
- Track your Pixals and crafted/recycled items.
- Monitor marketplace activity for drops.
- Backup tool when AtomicHub is busy.

## Tips & Best Practices
- Use alongside waxblock.io for full blockchain data.
- Report bugs/requests via their Telegram.
