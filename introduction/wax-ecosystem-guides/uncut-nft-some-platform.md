# Uncut (NFT SoMe Platform)

**Uncut** is a social platform built for NFT collectors and creators. It integrates directly with WAX (and other chains) and allows you to showcase your collection, share drops, and connect with the community in a more visual, NFT-focused way.

It works similarly to Twitter/X but is tailored for the NFT space, with easy ways to display your Pixals and other holdings.

You can access Uncut directly from Cloud Wallet (WAX Social) or via their main site.

For more details on how to use it, see the WAX Social guide in the Cloud Wallet section.
