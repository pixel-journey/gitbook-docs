# Creating new Wax accounts via Waxblock.io

This guide walks you through creating a brand new WAX account using WaxBlock.io and claiming control of an existing WAX account via MyCloudWallet.com. We'll cover key generation, account creation, importing accounts into your Anchor Wallet for easy management, and considerations for securing shorter account names.

## Understanding Keys on WAX Account Keys

Before diving in, it's essential to understand key pairs in blockchain technology. On EOSIO-based blockchains like WAX, each account is controlled by a pair of cryptographic keys: a public key and a private key.

* **Private Key (PVT\_K1\_):** This is a secret, random string that acts as your account's password. **Never share your private key with anyone!** Losing access to your private key means losing access to your account.
* **Public Key (PUB\_K1\_):** This is derived from its private key and is used to verify transactions. You can share your public key freely.

The number of possible key combinations is astronomically large, making collisions (duplicate keys) practically impossible.

## Part 1: Creating a New WAX Account via WaxBlock.io

### 1. Generate a Key Pair&#x20;

The first step is to generate a new key pair. You can use a tool like WaxBlock's Key Generator:

{% embed url="https://waxblock.io/wallet/utilities" %}
[https://waxblock.io/wallet/utilities](https://waxblock.io/wallet/utilities)
{% endembed %}

This tool will provide you with two long strings:

* A public key starting with `PUB_K1_...`
* A private key starting with `PVT_K1_...`

{% hint style="info" %}
**Important:** Store your private key (`PVT_K1_..`) in a secure location. This is crucial for accessing and managing your account. \*\*Each time you reload the page or hit the generate button, it gives you a new, entirely random pair.



Ensure you select a pair, and stick with it. Any pair generated by the tool is valid, but only if you use both the public and private key from the same generated pair. If you don't use them, they essentially disappear, and the odds of generating that exact pair again are astronomically low.
{% endhint %}

{% hint style="info" %}
Reminder: Any pair the key generator provides is a mathematically matching set. The Private Key grants access to own/manage any Accounts created to be owned by its paired Public Key.
{% endhint %}

### **2. Create a WAX Account**

Go to the WaxBlock Account Creator: [waxblock.io/wallet/create-account](https://waxblock.io/wallet/create-account).

{% embed url="https://waxblock.io/wallet/create-account" %}
Waxblock Account Creator Tool
{% endembed %}

* Enter your desired 12-character account name.&#x20;

{% hint style="info" %}
Note that account names must be exactly 12 characters long. Account names can only use characters a-z and numbers 1-5.
{% endhint %}

* In the "Public Owner Key" and "Public Active Key" fields, paste the PUB\_K1 key you generated earlier.&#x20;

For simplicity, you can use the same public key for both fields. Alternatively, you can generate two different key pairs and use the respective public keys.

* Resource Allocation: The default NET, CPU, and RAM amounts are sufficient for creating the account. However, if you are creating the account from an existing .wam account, you might want to allocate a little extra CPU or RAM based on your expected usage.&#x20;
* Click "Create Account" to register the 12-letter WAX account, which will be owned by the private key (PVT\_K1) that corresponds to the public key(s) you entered as its "Active/Owner" Keys.

{% hint style="danger" %}
Caution: After generating a key pair, make sure you save them correctly. Sometimes, users create an account and then realize they copy-pasted the wrong private key, losing access to their account forever.
{% endhint %}

### **3. Import the Account into Anchor Wallet**

Download and install Anchor Wallet from [www.greymass.com/anchor](https://www.greymass.com/anchor).

{% embed url="https://www.greymass.com/anchor" %}
[https://www.greymass.com/anchor](https://www.greymass.com/anchor)
{% endembed %}

Open Anchor Wallet and click "Add Account"., Select "Import Account" (usually the last option).

Copy and paste your private key (PVT\_K1) into the provided field.

**This is the only time you really need to enter your private key, and only do it into trusted wallets like Anchor.**

Anchor Wallet will search the blockchain for accounts associated with that private key and display them for you to import.

Select the account you just created and choose to import it.

You will be presented with options such as enabling biometrics for transaction signing. Configure these settings according to your preferences.

{% hint style="danger" %}
**Important Security Reminder:** Never share your private key with anyone, and never enter it into untrusted dApps or websites. Scammers may try to trick you into revealing your private key.&#x20;
{% endhint %}



### Optional: Securing Shorter Account Names&#x20;

If you desire an account name shorter than 12 characters (e.g., "bigboss"), you can participate in the Name Bid system:

1. Visit [waxblock.io/namebids](https://waxblock.io/namebids).
2. Bid for your desired name (re/overbidding a name in the queue, needs to increase the amount by more than +10%).
3. Your bid must be the highest Premium Namebid for 24 hours straight to win the name.&#x20;

## Part 2: Soft Claiming an Existing WAX Account from MyCloudWallet.com&#x20;

If you already have a WAX account created via MyCloudWallet.com (WCW), you might want to gain more direct control over your account by claiming the keys and importing them into a wallet like Anchor.&#x20;

### 1. Find Your/Generate a New Key Pair&#x20;

If you've already created your own Wax Accounts previously, and you already have control of your own Public/Private Keys from the past, then you can re-use one of these and take over the ownership of your Cloudwallet to be held by the same Keys there (much like a Key Ring)

Otherwise, generate a new key pair using a tool like WaxBlock’s Key Generator, like discussed up previously: [https://waxblock.io/wallet/utilities](https://waxblock.io/wallet/utilities)&#x20;

This new key pair will be used to take ownership of your account.&#x20;

### 2. Soft Claim via MyCloudWallet

1. Go to MyCloudWallet.com and log in to your account.,
2. Navigate to "Settings" -> "Account Claiming.",
3. Enter the newly generated public and private keys in the appropriate fields. By doing this, you are assigning the new key pair to your existing account.,

### **Soft Claim vs. Hard Claim**:

* **Soft Claim:** You can still use the MyCloudWallet.com portal and all its features, even after claiming a copy of your private keys to import/control from Anchor.
* **Hard Claim:** You take over full control, forcing MyCloudWallet to delete your keys from their servers. In this case, you would not be able to log in via MyCloudWallet anymore.

{% embed url="https://www.mycloudwallet.com/settings/account-claim" %}
[https://www.mycloudwallet.com/settings/account-claim](https://www.mycloudwallet.com/settings/account-claim)
{% endembed %}

Follow the same steps as in Part 1 to import the account into Anchor Wallet using the new private key you generated and claimed.
