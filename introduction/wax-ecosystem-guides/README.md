# 🏠 WAX Ecosystem Guides (2026 Edition)

Welcome to the comprehensive **WAX Ecosystem Guides** for Pixel Journey users. This handbook covers wallets, marketplaces, DEXes, explorers, governance, and more — updated for June 2026 realities.

## Current Status (June 2026)
- **AtomicHub**: Live and improved under new ownership (Detroit Ledger Tech / FACINGS with Rob's involvement). Reliable for Pixal trading, minting, and collections.
- **Cloud Wallet (My Cloud Wallet)**: Mobile apps discontinued. Focus on passkey migration (Google Passkey Manager), soft/hard claim for key control, transition to Anchor or upcoming PxWallet.
- **Alternatives**: NeftyBlocks (Trade-to-Earn, occasional reliability notes), F12Key (pro tools), NFTHive, WaxItems.
