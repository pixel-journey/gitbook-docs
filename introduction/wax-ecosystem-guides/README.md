# 🏢 Wax Ecosystem Guides

Welcome to the **Wax Ecosystem Guides** section — your practical handbook for navigating the WAX blockchain and its vibrant tools, marketplaces, wallets, and community resources.

As part of the Pixel Journey, understanding WAX is essential. This is where we build our foundation: minting and trading Pixals, participating in the PXJ economy, recycling & crafting, staking, governance, and connecting with the wider community.

These guides are designed to be clear, up-to-date (as of 2026), and beginner-friendly while still useful for more experienced users. They cover everything from setting up your first wallet to advanced marketplace features, common questions, and best practices.

Whether you’re brand new to WAX or already active in the ecosystem, you’ll find step-by-step instructions, tips, safety notes, and direct links to the best current tools.

**How to use this section:**
- Start with the **Common Questions** if you have a specific issue
- Explore the **Wallet** guides (Cloud Wallet, Anchor) to get set up safely
- Dive into **Marketplaces** (Neftyblocks, etc.) when you’re ready to trade or create
- Check the **FAQ** pages for quick answers to the most common WAX questions

We regularly review and update these guides to reflect the current state of the WAX ecosystem. If something feels outdated or you have suggestions, let us know on Discord!

Let’s make your time on WAX smooth, safe, and enjoyable as we continue the Pixel Journey together. 🚀
