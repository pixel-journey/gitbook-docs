# Fluctuations in Available CPU on WAX Blockchain

CPU availability on WAX fluctuates based on overall network activity. When the blockchain is busier, CPU becomes more scarce, so you receive less CPU per staked WAXP.

To check how much CPU a specific transaction will use, you can use any of the block explorers mentioned in other guides.

For a deeper explanation, read these resources:

- [PSA: Understanding CPU Usage and Fluctuations](https://wax-io.medium.com/psa-understanding-cpu-usage-and-fluctuations-in-accordance-with-staking-on-wax-84f88ef03f5f)
- Check the 🔧┃tech-updates channel in the official [WAX Discord](https://discord.gg/wax-blockchain-785124017430331392)

Always keep an eye on your resources before making transactions, especially during busy periods.
