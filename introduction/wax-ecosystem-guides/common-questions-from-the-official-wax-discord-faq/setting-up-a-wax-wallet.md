# Setting Up a WAX Wallet

Here's a simple step-by-step guide:

1. Go to [https://mycloudwallet.com/](https://mycloudwallet.com/)
2. Choose to sign up with email or use social login (Google, Facebook, or Discord).
3. Follow the on-screen prompts and accept the terms.
4. Your wallet is now ready to send and receive WAX assets.

**For extra security:** Link your wallet to Discord in the 🔗┃link-wallet channel.

**Helpful video:** [WAX Cloud Wallet Setup Guide](https://youtu.be/L4wTqNAG6sc?si=_Wj6rX5lISE3yYiq)

**Prefer Anchor Wallet instead?** Check this guide: [How to use Anchor instead of Cloud Wallet](https://medium.com/@di0nix/how-to-use-your-wax-account-with-anchor-instead-of-wax-cloud-wallet-7bfe5d8fb3ad)

Always prioritize security when setting up any wallet.
