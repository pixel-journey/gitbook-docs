# Two-Factor Authentication

If you lose access to your 2FA codes, use the **recovery code** you received when you first enabled 2FA on WAX Cloud Wallet.

This is an 8–10 character alphanumeric string. Enter it in the normal 2FA field when logging in (it is case-sensitive).

**Important:** The WAX support team cannot manually disable 2FA for you.
