### Bountyblok Contests

Bountyblok contests can be initiated either to by default require all participants to login with a Wax or Polygon account, depending on whether it is a Wax or Polygon type of bountyblok being run.

While the Wax Network type bountybloks also offers the option for checking Polygon NFT ownership as part of tasks possible there, then Polygon based bountyblok contests **cannot** add in Wax Network based tasks.



In unique/valuable bountyblok tasks easily available to setup in contests there we have:

* NFT (or for Wax contests, also Token) Holding tasks
* On-chain contract action tasks (incentivizing completing a specific contract action on the network)
* Social Media tasks (such as liking/reposting/commenting on X, Medium, or similar)
* Quiz and poll tasks
* Discord/TG Join Links
