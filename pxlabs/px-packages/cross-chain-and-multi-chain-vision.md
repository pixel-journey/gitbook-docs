# 🌐 Cross-Chain & Multi-Chain Vision — Px Portals

> **⚠️ DEVELOPMENT STATUS (June 2026)**  
> The cross-chain and multi-chain vision for Px Portals is in the early foundational planning stage. Core principles and high-level architecture direction are being defined. Concrete implementation work on specific chains beyond WAX is still ahead.  
> **We welcome high-level feedback** on desired cross-chain capabilities and priorities. Join our Discord to participate in early discussions.

**Px Portals** is being designed from the ground up with a clear long-term goal: enabling Pixel Journey experiences to work seamlessly across multiple blockchains while maintaining a unified, user-friendly experience.

This page outlines the high-level vision for how Px Portals will support multi-chain and cross-chain journeys in the future.

## 🎯 Why Multi-Chain Matters for Pixel Journey

While Pixel Journey is currently deeply rooted in the WAX ecosystem, the long-term vision includes thoughtful expansion to other chains. Px Portals is the key infrastructure that will make this expansion powerful rather than fragmented.

Key reasons for a multi-chain approach:

- Reach more users across different blockchain communities.
- Leverage strengths of different chains (e.g., WAX for NFTs and gaming, other chains for different DeFi or scalability characteristics).
- Future-proof the ecosystem against changes in any single chain’s landscape.
- Enable new types of experiences that benefit from cross-chain mechanics.

## 🔗 High-Level Cross-Chain Capabilities (Vision)

Px Portals aims to eventually support capabilities such as:

- **Unified Identity Across Chains** — Users can maintain a coherent identity and progression across different blockchains.
- **Asset Portability** — Secure, user-controlled movement or representation of value (tokens, NFTs, resources) between supported chains.
- **Shared State & Progress** — Key progress, achievements, and staking positions can be recognized or mirrored across chains where it makes sense.
- **Seamless Experience Handoffs** — Users can start an action on one chain and continue related activities on another with minimal friction.
- **Cross-Chain Orchestration** — Platforms like PxStaking, PxHot, or PxMarket can have meaningful interactions across chains in the future.

These capabilities will be introduced gradually and only where they add clear user value, while always prioritizing security and simplicity.

## 🛠️ How Px Packages Support This Vision

The modular Px Packages approach is critical for multi-chain success:

- Shared packages can be adapted or extended for different chains without duplicating effort.
- Core logic (wallets, notifications, state management, etc.) can be reused while chain-specific parts are cleanly isolated.
- New chain support can be added more efficiently because the foundational architecture already accounts for it.
- Long-term maintenance becomes much more sustainable across multiple chains.

## 🚀 Current Status & Outlook

- High-level architecture and principles for multi-chain support are being established.
- Initial focus remains on strengthening the WAX-native experience and Px Portals within the current ecosystem.
- Concrete work on additional chains will follow once the foundational layer is more mature.
- The vision is intentionally flexible — we want to expand thoughtfully to chains that genuinely add value to Pixel Journey users.

We are not rushing cross-chain features. The priority is building a solid, secure, and maintainable foundation first.
