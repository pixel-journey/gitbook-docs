# 🛡️ Security Tips on Solana

Solana security follows similar principles to other chains but with SVM-specific considerations (e.g., transaction fees paid in SOL, program-based accounts).

## Core Principles
- Never share seed phrases.
- Use hardware wallets (Ledger via Phantom/Solflare).
- Verify all transactions and dApps.
- Start small on new protocols.
- Revoke approvals where possible.

## Solana-Specific Notes
- Fast transactions = be careful with rushed decisions.
- New token launches can be risky.
- Use reputable wallets and explorers (Solscan, SolanaFM).

Builds strong habits for fast-chain environments that complement WAX activities.
