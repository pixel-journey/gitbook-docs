# 🌉 Bridges on Solana

Bridges enable asset movement between Solana and other chains (WAX, EVM chains, etc.). Important for future PxPortals and cross-chain strategies.

## Key Bridges
- Official and audited bridges for Solana ↔ other ecosystems.
- Focus on security and low fees where possible.

## Getting Started
1. Use Phantom or Solflare.
2. Choose trusted bridge.
3. Start with very small test transfers.
4. Monitor on explorers.

## Safety
- Only use audited bridges.
- Verify contracts.
- Start tiny.
- Revoke approvals.

## Pixel Journey Relevance
Cost-effective way to test cross-chain mechanics that will matter more with PxPortals.
