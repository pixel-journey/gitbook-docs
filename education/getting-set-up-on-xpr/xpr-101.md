# XPR Network 101

## What is XPR Network?

XPR Network (previously known as **Proton** or **ProtonChain**) is a Layer 1 blockchain launched by **Metallicus** in 2019. It is built on the **Antelope** framework (the same codebase that powers WAX, EOS, and Telos), which means its architecture will feel immediately recognizable to anyone who has used WAX.

The core mission of XPR Network is to make blockchain transactions as easy and familiar as using a bank app — with real-name identity verification, feeless user transactions, and direct fiat on/off-ramp integration via **Metal Pay**.

Its native token is **XPR**, used for staking to access network resources, participating in governance, and DeFi across the ecosystem.

## How XPR Network Relates to WAX

Both XPR Network and WAX are built on the **Antelope** framework, which means they share foundational similarities:

| | WAX | XPR Network |
|---|---|---|
| **Framework** | Antelope (EOSIO) | Antelope (EOSIO) |
| **Consensus** | DPoS | DPoS |
| **Account type** | Human-readable name (e.g. `pixeljourney`) | Human-readable name (e.g. `yourname`) |
| **Transaction fees** | Resource-based (CPU/NET/RAM staking) | Feeless for most users (staking covers resources) |
| **NFT standard** | AtomicAssets | AtomicAssets |
| **Primary NFT marketplace** | AtomicHub, NeftyBlocks | XPR Market |
| **Native token** | WAXP | XPR |

Because both chains use **AtomicAssets** as their NFT standard, the on-chain NFT structure on XPR Network will be very familiar to anyone who has minted or traded on WAX.

## Accounts on XPR Network

Like WAX, XPR Network uses **human-readable account names** rather than hexadecimal addresses. Your account might look like:

```
yourname
```

Up to 12 characters, letters and numbers only, no special characters (except a period for sub-accounts). This is your identity on the network — used for receiving tokens, signing transactions, and interacting with dApps.

When you create a wallet with **WebAuth Wallet** or register via **Metal Pay**, an XPR Network account is automatically created for you.

## Feeless Transactions

One of XPR Network's most user-friendly features is that **most standard transactions are feeless** for end users. This is possible because:

- Users stake XPR to access **CPU** and **NET** resources (same concept as WAX).
- For typical activity (trading NFTs, swapping tokens, staking), the resource usage is covered by staking a modest amount of XPR.
- The **resource model** automatically manages this — new accounts receive starter resources to begin with.

Practically speaking: you should never need to worry about running out of gas on XPR Network the way you might on Ethereum mainnet. The friction is much closer to WAX than to EVM.

## XPR Token

**XPR** is the native token of the network. It is used for:

- **Staking**: Stake XPR to power your account's CPU and NET resources for transactions.
- **Governance**: Vote on block producers (validators) who run the network.
- **DeFi**: Provide liquidity, farm yields, and stake in DeFi protocols on XPR Network.
- **Network fees for RAM**: Creating new accounts or storing data on-chain requires RAM, purchased with XPR.

XPR is listed on multiple exchanges and available via Metal Pay.

## NFTs on XPR Network

XPR Network uses the **AtomicAssets** standard — the same standard used on WAX. This means:

- NFT collections are organized the same way: collection → schema → template → mint.
- Tools and concepts from WAX (AtomicHub-style interfaces, blend mechanics, NFT farms) translate directly.
- **XPR Market** is the primary marketplace, similar in structure to AtomicHub on WAX.

For WAX users, the biggest practical difference is the marketplace and the ecosystem of projects — not the underlying NFT mechanics.

---

## Metal Pay Integration

A unique feature of XPR Network is deep integration with **Metal Pay** — a regulated fiat-to-crypto on-ramp and payment app built by the same company (Metallicus).

Metal Pay allows:
- Buying XPR directly with a bank account or debit card with no additional CEX steps.
- Sending XPR to other Metal Pay users via their phone number or username.
- Fiat off-ramp (sell XPR back to fiat) in supported regions.

This gives XPR Network one of the smoothest fiat on-ramp experiences in the entire blockchain space.
