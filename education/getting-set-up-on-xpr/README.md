# Getting Set Up on XPR Network

XPR Network (formerly ProtonChain) is a Layer 1 blockchain built on the **Antelope** (formerly EOSIO) framework — the same underlying technology that powers WAX. If you have been active on WAX, many of the concepts here will feel immediately familiar: account names instead of hex addresses, a resource model for transactions, and an active NFT marketplace ecosystem.

What makes XPR Network distinct is its focus on **feeless transactions** for end users, **DeFi primitives** built directly into the chain, and a growing NFT marketplace through XPR Market.

Its native token is **XPR**, used for staking, governance, and DeFi across the network.
