# Wallets on XPR Network

XPR Network wallets work differently from EVM wallets. Instead of a `0x...` hex address, your identity is a **human-readable account name** (up to 12 characters). Your wallet holds and manages that account.

## Which wallet should I use?

| Wallet | Best for | Platform |
|---|---|---|
| **WebAuth Wallet** | Most users — full-featured XPR wallet | Browser + Mobile |
| **Metal Pay** | Beginners, fiat on-ramp integration | Mobile (iOS + Android) |

Both wallets are **non-custodial by default** when using the full account key setup, though Metal Pay also offers a custodial mode for users who prefer not to manage keys directly.

> **Coming from WAX?** If you have used Cloud Wallet or Anchor, the concept of an account name (instead of a `0x` address) and staking for resources will feel very familiar. The account name is your on-chain identity.

Choose your wallet below:

- [WebAuth Wallet](webauth-101.md) — Recommended for most users
- [Metal Pay](metal-pay-101.md) — Best for beginners and fiat on-ramp
