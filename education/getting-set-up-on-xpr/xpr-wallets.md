# Wallets on XPR Network — Secure Access Options

**Wallets** for XPR Network focus on ease of use and security, leveraging the Antelope account model. Popular options include WebAuth Wallet and Metal Pay, which support seamless onboarding and feeless interactions.

## Recommended Wallets

### WebAuth Wallet
- Browser extension and mobile-friendly.
- Easy account creation and management.
- Supports XPR Network features like feeless transactions and DeFi.
- Good for beginners coming from WAX.

### Metal Pay
- Mobile-first wallet with strong security features.
- Integrated with XPR ecosystem tools.
- Supports staking, swaps, and NFT management.
- Hardware wallet integration options for advanced security.

### Other Options
- Anchor Wallet (with XPR support via plugins or updates).
- Any Antelope-compatible wallet that supports XPR Network endpoints.

## Getting Started with a Wallet
1. Download from official sources (verify links).
2. Create or import your XPR account.
3. Fund with XPR via on-ramp, exchange, or bridge from WAX/EVM.
4. Connect to XPR Market, swaps, or other dApps.

## Safety Best Practices
- Never share seed phrases or private keys.
- Use hardware wallets for larger holdings.
- Enable all available security features (2FA, biometrics where applicable).
- Verify contract addresses and dApp URLs before interacting.
- Start with small test transactions.
- Regularly review connected apps and revoke permissions.

## Pixel Journey Tips
- Use WebAuth or Metal Pay for daily XPR activities (NFT trading, DeFi).
- Pair with your Anchor Wallet on WAX for multi-chain management.
- Track assets across chains using portfolio tools.
- Bridge small amounts from WAX to test the feeless experience.

**Pro Tip**: WebAuth Wallet offers the smoothest onboarding for WAX users due to familiar account handling. Combine with Metal Pay for mobile use. Always prioritize security — XPR's feeless nature makes experimentation easy, but best practices remain essential.
