# 🖼️ NFT Marketplaces on Base

**NFT Marketplaces on Base** are growing rapidly thanks to its low fees and fast transactions. While WAX leads with excellent AtomicAssets support, blends, and creator tools (AtomicHub, Neftyblocks, etc.), Base offers strong options for NFT trading, discovery, and community building. This provides Pixel Journey explorers with additional venues for experimentation and inspiration at much lower costs than Ethereum mainnet.

## Key NFT Marketplaces on Base

- **Established Platforms**: Explore trusted marketplaces for buying, selling, and discovering Base NFTs (e.g., integrations with OpenSea, Magic Eden, or Base-native platforms).
- **Standards**: Base supports standard ERC-721/ERC-1155 NFTs; always verify compatibility.
- **Integration with Wallets**: Most marketplaces work seamlessly with MetaMask, Rabby, and other EVM wallets.

## Getting Started with NFTs on Base

1. Use a compatible EVM wallet like MetaMask or Rabby.
2. Add the Base network and bridge a small amount of ETH or tokens.
3. Browse or search for collections on a trusted marketplace.
4. Review listings, provenance, and contract details carefully.
5. Start with small test purchases to learn the interface and fees.

## Safety Best Practices

- Verify the marketplace and contract addresses from official sources or explorers (basescan.org).
- Read all transaction details before confirming (especially approvals).
- Be cautious of new or unverified collections — DYOR on rarity, utility, and team.
- Revoke approvals regularly.
- Use hardware wallets for significant NFT holdings.
