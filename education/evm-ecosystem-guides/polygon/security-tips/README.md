# 🛡️ Security Tips on Polygon

Security on Polygon follows standard EVM best practices. Low fees make interactions cheap but also make spam and malicious contracts easier — stay vigilant.

## Core Principles
- Never share seed phrases.
- Use hardware wallets for significant assets.
- Always read transaction details.
- Start small on new dApps.
- Revoke approvals regularly.

## Polygon-Specific Notes
- Low fees = easier spam; verify everything.
- Bridges from WAX/Ethereum: test small first.
- DYOR on new protocols and yields.
