# 🌉 Bridges on Polygon

Bridges enable asset movement between Polygon and other chains (WAX, Ethereum, Base, Solana, etc.). Essential for cross-chain strategies and future PxPortals.

## Key Bridges
- Official and audited bridges for Polygon ↔ other ecosystems.
- Focus on security and low fees.

## Getting Started
1. Use EVM wallet.
2. Choose trusted bridge.
3. Start with very small test transfers.
4. Monitor on explorers.

## Safety
- Only use audited bridges.
- Verify contracts.
- Start tiny.
- Revoke approvals.

## Pixel Journey Relevance
Cost-effective way to test cross-chain mechanics that will matter more with PxPortals.
