## 🛡️ Shared Safety & Best Practices Across All Antelope Chains

- **Start Tiny & Scale Slowly**: Test every new dapp, DEX, or NFT platform with dust amounts first. Learn the UI, fees, and risks.
- **Resource Management**: Always monitor/stake sufficient CPU/NET (or use REX on EOS). Running out mid-transaction is frustrating and costly in opportunity.
- **Wallet Hygiene**: Primary recommendation for WAX = **Anchor Wallet** (desktop + mobile). For XPR/EOS explore official or trusted options (e.g. Anchor-compatible where available). Use hardware wallets (Ledger etc.) for larger holdings.
- **Revoke Approvals Regularly**: Smart contracts can retain infinite approvals. Use trusted revoke tools or manual checks on explorers. Never approve what you don't understand.
- **Scam Awareness**: Fast ecosystems = fast scams (fake airdrops, phishing sites mimicking AtomicHub/Neftyblocks, malicious contracts). Verify URLs, contracts on official explorers (waxblock.io, bloks.io, eosauthority.com, etc.). Never click random links from Discord/Twitter.
- **Smart Contract Risks**: Even audited contracts can have bugs. DYOR, read docs, check audits if available. Pixel Journey content highlights known cautions on specific platforms.
- **Hardware & Backup**: For anything beyond play money, use hardware. Backup seeds securely. Never share private keys.
- **Multi-Chain Portfolio Tracking**: Use tools like explorers + portfolio dashboards. Keep primary capital and focus on WAX/Pixel Journey.

**Pixel Journey Relevance**: These practices directly improve your safety and skill on WAX. Experimenting cheaply on XPR or EOS builds intuition for future PxPortals cross-chain moves and helps you spot opportunities (or red flags) faster in the core ecosystem.
