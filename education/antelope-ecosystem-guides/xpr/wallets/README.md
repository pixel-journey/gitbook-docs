# 🛠️ Wallets on XPR Network

XPR Network (formerly Proton) uses the Antelope account model with human-readable usernames. Anchor wallet works well, and there are XPR-specific options. Low or feeless transactions make it great for experimentation.

## Recommended Wallets
- Anchor (primary for Antelope compatibility)
- Official XPR wallets where available
- Hardware support via compatible interfaces

## Getting Started
1. Set up Anchor or preferred wallet.
2. Create/import XPR account (username style).
3. Acquire XPR for resources.
4. Start small.

## Safety
- Same Antelope security practices apply.
- Verify transactions carefully.

## Pixel Journey Relevance
XPR offers feeless UX and payment-focused features that complement WAX. Good for testing username simplicity and low-friction interactions.
