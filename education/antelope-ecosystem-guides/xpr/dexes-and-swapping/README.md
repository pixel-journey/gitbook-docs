## Step-by-Step: Safe Swapping Workflow on XPR

1. Research the token pair and current rates.
2. Verify the official DEX URL and contract addresses.
3. Connect your wallet (Anchor recommended).
4. Start with a tiny test swap to confirm everything works.
5. Review all transaction details (amounts, fees, slippage) before confirming.
6. Monitor the transaction on explorers.
7. Revoke approvals regularly after use.

## Security Tips for DEX Usage on XPR

- Never approve unlimited token spending unless necessary (revoke regularly).
- Be extremely cautious of new or low-liquidity tokens (higher scam risk).
- Use hardware wallets for large holdings when possible.
- Start small when interacting with new pools or tokens on XPR.
- Be extra cautious of new or high-value projects.
