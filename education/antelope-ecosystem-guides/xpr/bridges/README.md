# 🌉 Bridges on XPR Network

Bridges enable asset movement between XPR and other chains (WAX, EVM, Solana, etc.). Important for future PxPortals.

## Getting Started
1. Use compatible wallet.
2. Choose trusted bridge.
3. Start with very small test transfers.
4. Monitor on explorers.

## Safety
- Only use audited bridges.
- Verify contracts.
- Start tiny.

## Pixel Journey Relevance
Cost-effective way to test cross-chain mechanics.
