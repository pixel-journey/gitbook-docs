# 🔮 Neftyblocks on WAX

> **⚠️ Important Safety Note**  
> Neftyblocks has undergone ownership changes that have affected reliability for some users. Always DYOR thoroughly, verify current status before using advanced features, and start small when testing drops, blends, or staking.

Neftyblocks is a powerful creator platform on WAX focused on **drops, blends, staking tiers, bulk tools, and advanced collection mechanics**. It has been widely used for complex NFT projects and community engagement features.

## Key Features

- Advanced drop and blend creation tools
- Staking tiers and reward systems
- Bulk minting and management tools
- Creator studio for complex mechanics
- Integration with various WAX standards

## What Neftyblocks Is Used For

Neftyblocks allows collection owners and creators to set up sophisticated on-chain experiences, including:

- Timed or permissioned NFT drops
- Blends (combining multiple assets into new ones)
- Tiered staking systems with rewards
- Bulk operations for managing large collections
- Advanced crafting and progression mechanics

These kinds of tools are foundational for many gaming and collectible projects on WAX.

## Pixel Journey Relevance
Neftyblocks-style mechanics (blends, drops, staking tiers) are very relevant to the Pixel Journey vision. Many of our future crafting, progression, and collectible systems will draw inspiration from or directly use similar patterns. Understanding these tools helps you appreciate the depth possible in the WAX ecosystem.

**Note on Current Status**: After ownership changes, some users have reported reduced reliability. We recommend using it with caution and having backup plans (alternative marketplaces/tools) for important activities.

## Security & Best Practices
- Always verify the latest status of the platform before committing significant assets.
- Start with small test blends or drops.
- Double-check all transaction details.
- Revoke approvals regularly.

**For Collection Owners**: When using advanced creator tools like Neftyblocks, you may be asked to grant **notify authority** or other collection-level permissions. These are powerful and different from regular token approvals. See the dedicated guide for details and risks:

→ [Atomic Assets Permissions & Notify Authority](education/common-guides/atomic-assets-permissions-and-notify-authority.md)

## Recommendation
Neftyblocks remains useful for understanding advanced creator mechanics on WAX, but treat it as a higher-risk tool compared to more stable alternatives. Monitor community feedback closely.
