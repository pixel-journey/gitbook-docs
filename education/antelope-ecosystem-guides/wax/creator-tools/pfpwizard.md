# 🧙 PFPWizard on WAX

> **⚠️ Important Safety Note**  
> Always DYOR and verify current platform status before using any features extensively. Some mechanics (such as raffles) may no longer be active.

PFPWizard is a specialized platform on WAX focused on **PFP collections**. It serves as one of the main places to view rankings, sales data, and leaderboards for approved PFP projects on WAX. Almost every major PFP collection on WAX is listed there.

## What PFPWizard Is Used For

PFPWizard allows users to:

- Browse and inspect rankings of PFP assets across approved collections
- View top sales and top number of sales rankings for collections
- Sort and rank collections by metrics such as number of sales, total trading volume, and other performance indicators
- Participate in the gems system (a reward mechanic tied to trading activity directly on the platform)
- Access breeding mechanics (currently limited to PFPWizard’s own Whizzies collection and select partnered event collections)

It is particularly valued for its transparent sales and volume rankings, which many in the WAX PFP community use to compare project performance.

**Current Status Notes**:
- The gems raffle system is no longer active.
- Gems can still be upgraded for fun or for the collectible value of low-mint / high-gem assets.
- Breeding is generally only available for PFPWizard’s own collection and specific partnered events (e.g., past collaborations like Wagsteer). It is not currently open for arbitrary creators to activate breeding on their own collections.
