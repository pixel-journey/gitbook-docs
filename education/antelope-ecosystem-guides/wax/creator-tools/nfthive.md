# 🐝 NFTHive on WAX

> **⚠️ Important Safety Note**  
> Always verify current platform status and DYOR before using any creator tools extensively. Some tools on WAX have experienced changes in reliability over time.

NFTHive is a creator-focused platform on WAX that offers tools for **drops, crafts, collection management, and a secondary market** with its own reward system (Honey).

## What NFTHive Is Used For

NFTHive provides creators with tools to:

- Create and manage drops
- Set up crafting mechanics
- Handle collection administration
- Trade on its secondary marketplace
- Earn rewards through its Honey system

It combines creator tools with marketplace functionality, making it useful for projects that want integrated crafting and trading experiences.

## Pixel Journey Relevance
NFTHive-style crafting and reward mechanics align well with the Pixel Journey focus on ingredients, crafting, and progression. Understanding how these tools work helps you see the possibilities for our own PxPackages and mini-games.

## Security & Best Practices
- Start small when exploring new features.
- Verify all transactions carefully.
- Revoke approvals regularly.
- Monitor community feedback for any changes in platform reliability.
