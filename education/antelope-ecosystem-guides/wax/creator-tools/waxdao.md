# 🏛️ WaxDAO on WAX

> **⚠️ Important Safety Note**  
> WaxDAO involves staking, farming, and token creation features. Always DYOR thoroughly, start with small amounts, and verify current platform status before committing assets. Some platforms have had ownership changes that affected reliability.

WaxDAO is a platform on WAX focused on token and NFT farms, staking, whitelisting, and creating custom tokens. It functions more as a creator and staking platform than a traditional marketplace.

## What WaxDAO Is Used For

WaxDAO provides tools for:

- Creating and managing token and NFT farming/staking pools
- Building custom tokens
- Setting up whitelists and access control
- Supporting community and project features

It is particularly useful for projects that want to create their own yield opportunities or token systems on WAX.

## Pixel Journey Relevance
WaxDAO-style staking and farming mechanics are relevant to the Pixel Journey vision of yield, progression, and ecosystem participation. Understanding these tools helps appreciate the range of possibilities on WAX and can inspire features in our own PxStaking and PxPackages.

While not a primary marketplace, it offers useful yield and creation tools that complement other parts of the ecosystem.

## Security & Best Practices
- Always verify the latest status and reputation of the platform.
- Start with small test positions when exploring new farms or pools.
- Double-check all transaction details and contracts.
- Revoke approvals regularly.
- Be cautious of platforms that have undergone significant ownership or operational changes.

**For Collection Owners & Token Creators**: When using platforms that involve collection or token permissions, be aware of **notify authority** and other collection-level permissions. These differ from regular token approvals. See:

→ [Atomic Assets Permissions & Notify Authority](education/common-guides/atomic-assets-permissions-and-notify-authority.md)
