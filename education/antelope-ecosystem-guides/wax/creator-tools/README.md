# 🛠️ Creator Tools on WAX

> **⚠️ Important Safety Note**  
> Many creator tools on WAX involve smart contracts, drops, blends, staking, and breeding. Always DYOR, start small when testing new tools, and verify contracts before interacting. Some tools have had ownership changes and may be less reliable — use caution.

WAX has a rich set of creator-focused tools that allow you to build, drop, blend, stake, craft, and manage collections and tokens. These tools are essential for anyone looking to create value in the Pixel Journey ecosystem.

## Key Creator Tools on WAX

### Neftyblocks
Neftyblocks is a powerful platform for drops, blends, staking tiers, bulk tools, and creator studio features.

[Read the full Neftyblocks guide →](neftyblocks.md)

**Note**: Reliability has decreased for some users after ownership changes. DYOR and use with caution.

### NFTHive
NFTHive offers creator tools, drops, crafts, collection management, and a secondary market with rewards (Honey).

[Read the full NFTHive guide →](nfthive.md)

### PFPWizard
PFPWizard provides breeding mechanics, gems, magic power systems, leaderboards, and raffles.

[Read the full PFPWizard guide →](pfpwizard.md)

### WaxDAO
WaxDAO supports token and NFT farms, staking, whitelisting, and creating custom tokens. It functions more as a creator and staking platform.

### F12Key
F12Key serves as both a marketplace helper and a powerful creator tool for quick access to drops, blends, and setup actions.

## Pixel Journey Relevance
Creator tools are fundamental for building and sustaining value in the Pixel Journey ecosystem. Many of our future PxPackages and mini-games will rely on these kinds of mechanics for crafting, staking, progression, and collectibles. Mastering them now gives you a strong advantage as we expand.

## Getting Started with Creator Tools
- Start with simpler tools (basic drops or blends) before moving to complex staking or breeding.
- Always verify the latest status of each tool.
- Combine tools thoughtfully with PxWallet and PxMarket for the best experience.
