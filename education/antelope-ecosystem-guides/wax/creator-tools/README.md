# 🛠️ Creator Tools on WAX

> **⚠️ Important Safety Note**  
> Many creator tools on WAX involve smart contracts, drops, blends, and staking. Always DYOR, start small when testing new tools, and verify contracts before interacting. Some tools have had ownership changes and may be less reliable — use caution.

WAX has a rich set of creator-focused tools that allow you to build, drop, blend, stake, and manage collections and tokens. These tools are essential for anyone looking to create value in the Pixel Journey ecosystem and the broader WAX economy.

## Key Creator Tools on WAX

### Neftyblocks
Neftyblocks is a powerful platform for drops, blends, staking tiers, bulk tools, and creator studio features. It has been widely used for complex collection mechanics.

**Note**: After ownership changes, reliability has decreased for some users. DYOR and consider alternatives when possible.

### NFTHive
NFTHive offers creator tools, drops, crafts, collection management, and a secondary market with rewards (Honey).

### PFPWizard
PFPWizard provides breeding mechanics, gems, magic power systems, leaderboards, and raffles for collections.

### WaxDAO
WaxDAO supports token and NFT farms, staking, whitelisting, and creating custom tokens. It is more of a creator and staking platform than a traditional marketplace.

### F12Key
F12Key is a quick-access tool that serves both as a marketplace helper and a creator tool for accessing and setting up drops and blends.

## Pixel Journey Relevance
Creator tools are fundamental for building and sustaining value in the Pixel Journey ecosystem. Many of our future PxPackages and mini-games will rely on these kinds of tools for crafting, staking, and progression systems. Mastering them now will give you a strong advantage as we expand cross-chain.

## Getting Started with Creator Tools
- Start with simpler tools (e.g., basic drops or blends) before moving to complex staking or breeding mechanics.
- Always verify the latest status of each tool, as some have changed ownership or functionality.
- Combine tools with PxWallet and PxMarket for a more integrated Pixel Journey experience.
