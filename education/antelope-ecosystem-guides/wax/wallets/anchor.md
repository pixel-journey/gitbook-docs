# 🔧 Anchor Wallet on WAX

> **⚠️ Important Safety Note**  
> Always use official or well-audited wallets. Never share your private keys or seed phrases. Be extremely cautious with any website or tool asking for your private keys. Start small when testing new wallets or features. DYOR.

Anchor is one of the most popular and trusted desktop and mobile wallets for WAX (and the broader Antelope ecosystem). It is widely used by serious users, creators, and developers.

## Key Features

- Strong support for WAX and other Antelope chains
- Desktop and mobile versions available
- Hardware wallet integration (Ledger)
- Excellent for power users and developers
- Good transaction signing and permission management

## Pixel Journey Relevance
Anchor remains an excellent choice for many Pixel Journey participants who want a reliable, full-featured wallet with strong hardware support. While **PxWallet** is our top recommendation for the best integration with PxMarket, PxStaking, and future PxPackages, Anchor is still a very solid option — especially for users who prefer desktop workflows or need advanced features.

Many long-time WAX users and creators continue to use Anchor successfully alongside our ecosystem tools.

## Security Best Practices

- Use hardware wallet integration (Ledger) for larger holdings when possible.
- Never share your seed phrase or private keys.
- Double-check all dApp URLs and contract addresses.
- Revoke token approvals regularly.
- Start with small amounts when trying new dApps or features.

## Recommendation
For most users deeply engaged with the Pixel Journey ecosystem, we recommend **PxWallet** for the best native integration. However, **Anchor** remains a trusted and powerful alternative, particularly for desktop users or those who value its mature feature set and hardware support.
