# ☁️ Cloud Wallet on WAX

> **⚠️ Important Safety Note**  
> Cloud Wallet is a convenient custodial option for many users. However, because it is custodial, you do not control the private keys. For larger holdings or long-term security, we strongly recommend non-custodial wallets with hardware support. DYOR and understand the trade-offs.

Cloud Wallet is a popular and user-friendly custodial wallet widely used on WAX. It offers easy onboarding, good mobile support, and convenient features for many everyday users.

## Key Features

- Easy-to-use interface, especially for beginners
- Good mobile experience
- Convenient for quick interactions and smaller holdings
- Widely supported by WAX dApps and marketplaces

## Pixel Journey Relevance
Cloud Wallet has been used by many in the Pixel Journey community, especially newer users. While it offers convenience, we recommend transitioning to a non-custodial solution like **PxWallet** or Anchor (with hardware) for better security and control as you become more active in the ecosystem.

Our long-term vision with PxWallet is to provide both excellent UX and strong self-custody options tailored to Pixel Journey participants.

## Security Best Practices

- Never share your Cloud Wallet credentials or recovery information.
- Be cautious of phishing sites pretending to be Cloud Wallet.
- For larger holdings, consider moving assets to a non-custodial wallet with hardware support.
- Regularly review connected dApps and revoke access when no longer needed.
- Start small when exploring new features.

## Recommendation
Cloud Wallet can be a convenient starting point for new users. However, for serious engagement with Pixel Journey (especially staking, crafting, and larger collections), we recommend moving to **PxWallet** or Anchor with hardware integration for better security and control.
