# 👛 PxWallet — The Pixel Journey Wallet

> **⚠️ Important Safety Note**  
> PxWallet is our own non-custodial Web3 wallet built for the Pixel Journey ecosystem. Like any wallet, security depends on how you use it. Never share your seed phrase or private keys. Use hardware wallet features when available for larger holdings.

**PxWallet** is the official wallet developed for the Pixel Journey ecosystem. It is designed to be a powerful, secure, and deeply integrated Web3 wallet that works across WAX (and eventually other chains via PxPortals).

## Key Features

- **Native Pixel Journey Integration**: Seamless connection with PxMarket, PxStaking, PxSwap, and future PxPackages.
- **PxVault Support**: Built-in support for PxVault — our secure key management and automation layer that unlocks advanced features based on your Pixel Journey ownership and progress.
- **Multi-Chain Vision**: Designed with future cross-chain and multi-chain support in mind.
- **Creator & Power User Friendly**: Tools tailored for active participants in the Pixel Journey economy (crafting, staking, trading, etc.).

## PxVault — A Core Part of PxWallet
PxVault is the secure key and automation layer inside PxWallet. It allows you to safely manage private keys and unlock automation features (such as advanced staking strategies or yield profiles) based on your ownership of Pixel Journey assets and achievements.

This makes PxWallet not just a standard wallet, but a true companion for serious Pixel Journey participants.

## Pixel Journey Recommendation
**PxWallet is our top recommended wallet** for engaging with the full Pixel Journey ecosystem on WAX. While Anchor remains excellent for general WAX use, PxWallet offers superior integration with our tools and future features.
