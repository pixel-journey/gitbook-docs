# 🔎 EOSAuthority Explorer on WAX

> **⚠️ Important Safety Note**  
> Always use trusted, well-known explorers. Be cautious of fake explorer sites. Verify data across multiple sources when making important decisions. DYOR.

EOSAuthority is a long-standing and widely used explorer for WAX (and historically EOS). It provides detailed on-chain data, account information, and useful tools for monitoring activity.

## Key Features

- Comprehensive account and transaction explorer
- Resource usage tracking (CPU, NET, RAM)
- Contract and permission inspection
- Historical data and analytics
- User-friendly interface trusted by many in the community

## Pixel Journey Relevance
EOSAuthority has been a reliable tool for many Pixel Journey participants to verify transactions, check resource balances, and monitor on-chain activity related to Pixals and ecosystem interactions. It serves as a solid complement to waxblock.io.

As our own tools (PxWallet, PxMarket, etc.) evolve, we aim to provide seamless built-in analytics, but external explorers like EOSAuthority remain valuable for verification and deeper inspection.

## Security & Best Practices

- Always verify you are on the official EOSAuthority site.
- Cross-reference important data with other explorers (e.g., waxblock.io) when making decisions.
- Use explorers to verify contract addresses before interacting with dApps.
- Never enter sensitive information on any explorer site.

## Recommendation
EOSAuthority is a trustworthy and feature-rich explorer. Many users prefer it alongside or instead of waxblock.io for certain tasks. Bookmark both for flexibility.
