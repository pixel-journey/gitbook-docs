# 🧪 WaxLabs on WAX

> **⚠️ Important Safety Note**  
> WaxLabs is primarily a development and testing environment. Use it responsibly. Never use mainnet keys or significant assets in testing environments without proper understanding.

WaxLabs is a development and testing lab for WAX. It provides tools and environments for builders and advanced users to experiment with smart contracts, tools, and on-chain actions in a safer or more flexible way than mainnet.

## Key Features

- Development and testing tools for WAX
- Sandbox environments for smart contract testing
- Utilities for advanced users and developers
- Experimentation space for new mechanics

## Pixel Journey Relevance
As we continue developing PxPackages, PxPortals, and various mini-games, having access to testing and development tools becomes increasingly important. Understanding the tools available to builders on WAX helps you appreciate what is possible and may allow more advanced community members to contribute ideas or even custom tools in the future.

## Security & Best Practices
- WaxLabs is intended for development and testing — do not use it with mainnet keys holding significant value unless you fully understand the risks.
- Follow official documentation and best practices for testing.
- Be cautious when interacting with any experimental features.

## Recommendation
WaxLabs is most useful for developers, advanced users, and those interested in building on WAX. For regular Pixel Journey activities (trading, crafting, staking), the main tools and marketplaces are more appropriate.
