# 🌉 Bridges on WAX

> **⚠️ Important Safety Note**  
> Bridges carry significant risks (smart contract exploits, bridge-specific hacks, liquidity issues, etc.). Always use official or well-audited bridges, start with tiny test transfers, and never bridge more than you can afford to lose. DYOR thoroughly before any bridge transaction. Be especially cautious with new or high-value projects.

WAX has bridge support to several other chains (Polygon, Base, Ethereum, and others via various bridge providers). Bridging is an important skill for future multi-chain expansion via PxPortals and cross-chain experiences.

## Key Bridges from WAX

WAX supports bridges to major EVM chains and other ecosystems. Common options include official WAX bridges and third-party solutions that have gained community trust.

**Popular Bridge Destinations**
- Polygon
- Base
- Ethereum
- Other EVM-compatible chains

**Best Practices**
- Only use official or community-verified bridges (double-check URLs and contracts).
- Always start with very small test transfers to familiarize yourself with the process, fees, and timing.
- Monitor transactions on explorers for both the source (WAX) and destination chains.
- Be aware of bridge-specific risks, any known issues, and current liquidity.
- Use hardware wallets for larger transfers when possible.
- Plan for potential delays during high network activity.

## Step-by-Step: Safe Bridging Workflow

1. Research the specific bridge and destination chain thoroughly.
2. Verify the official bridge URL and contract addresses from trusted sources.
3. Connect your wallet (preferably Anchor with hardware integration for larger amounts).
4. Start with a tiny test transfer (e.g., a small amount of a low-value token).
5. Confirm the transaction and monitor progress on both explorers.
6. Once the test succeeds, proceed with larger amounts if needed.
7. Revoke any unnecessary approvals after use.

## Security Tips for Bridging

- Double-check all bridge URLs and contract addresses every single time.
- Read every transaction detail carefully before confirming (especially recipient addresses and amounts).
- Revoke approvals after use when possible.
- Be extremely cautious during periods of high network activity or any reported bridge issues.
- Never bridge assets you cannot afford to lose if something goes wrong.
- Keep records of all bridge transactions for your own tracking.

## Pro Tips

- Bridge during lower network congestion periods when possible for better fees and speed.
- Use the same wallet address format expectations on both chains.
- Test the return bridge (destination back to WAX) with small amounts before committing larger positions.
- Stay updated via trusted Pixel Journey channels and official bridge announcements.
