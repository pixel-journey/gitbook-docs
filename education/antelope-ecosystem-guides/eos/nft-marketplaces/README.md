# 🖼️ NFT Marketplaces on EOS

**NFT Marketplaces on EOS** are evolving as the chain's ecosystem matures. While WAX leads with excellent AtomicAssets support, blends, and creator tools (AtomicHub, Neftyblocks, etc.), EOS offers growing options for NFT trading and discovery. This provides Pixel Journey explorers with additional venues for experimentation and inspiration.

## Key NFT Marketplaces on EOS

- **Established Platforms**: Explore trusted marketplaces for buying, selling, and discovering EOS NFTs.
- **Standards**: EOS supports standard and custom NFT implementations; always verify compatibility.
- **Integration with Wallets**: Most marketplaces work seamlessly with Anchor and other Antelope wallets.

## Getting Started with NFTs on EOS

1. Use a compatible wallet like Anchor.
2. Acquire EOS for fees and any tokens needed for purchases.
3. Browse or search for collections on a trusted marketplace.
4. Review listings, provenance, and contract details carefully.
5. Start with small test purchases to learn the interface and fees.

## Safety Best Practices

- Verify the marketplace and contract addresses from official sources or explorers (eosauthority.com, bloks.io).
- Read all transaction details before confirming (especially approvals).
- Be cautious of new or unverified collections — DYOR on rarity, utility, and team.
- Revoke approvals regularly.
- Use hardware wallets for significant NFT holdings.
