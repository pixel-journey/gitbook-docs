# 👛 Wallets on Vaulta (previously EOS)

> **⚠️ Important Safety Note**  
> Always use official or well-audited wallets. Never share your private keys or seed phrases. Be extremely cautious with any website or tool asking for your private keys. Start small when testing new wallets or features. DYOR.

Vaulta uses standard Antelope tooling, so wallets that work on WAX and XPR generally work well on Vaulta with proper network configuration.

## Recommended Wallet

### Anchor (Primary Recommendation)

**Anchor** is the most compatible and widely used wallet for Vaulta. It supports easy network management and works well with hardware wallets.

**Key Features**
- Strong Antelope support across WAX, XPR, Vaulta, etc.
- Easy network switching
- Hardware wallet support (Ledger)
- Good security features and session management

**Best For**
- Most users exploring Vaulta alongside WAX, XPR, and other Antelope chains
- Users who want one reliable wallet for multiple Antelope networks

### Other Options

- Native Vaulta/EOS wallets and tools — Check current recommendations from the Vaulta community for any chain-specific options.
- **Ledger + Anchor** — Recommended for larger holdings.

## Security Best Practices on Vaulta

- Use hardware wallets (Ledger) for significant holdings when possible.
- Never share your seed phrase or private keys.
- Double-check all dApp URLs and contract addresses.
- Revoke token approvals regularly.
- Start with small amounts when trying new dApps or tokens on Vaulta.
- Be extra cautious of new or high-value projects.
