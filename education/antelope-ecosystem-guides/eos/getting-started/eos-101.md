# 📝 EOS 101

## Introducing EOS: The Mature Antelope Foundation

EOS is the original high-performance, account-based blockchain that pioneered many of the features now common across the Antelope family. It offers fast finality, a flexible resource model via REX (Resource Exchange), strong governance, and a mature developer ecosystem. For Pixel Journey explorers, EOS provides a stable, battle-tested environment for broader dApp experimentation, governance participation, and inspiration that can inform strategies back on WAX.

### Key Features

- **DPoS Consensus**: Fast blocks and finality with delegated proof of stake.
- **REX Resource Model**: Dynamic resource exchange for CPU/NET — more flexible than pure staking on WAX.
- **Human-Readable Accounts**: Same excellent UX as WAX and XPR.
- **Mature Tooling & Governance**: Strong developer community, active governance, and improving NFT/DeFi support.
- **Native Token (EOS)**: Used for staking, governance, and resources.

### Why This Model Matters for Pixel Journey

EOS's maturity and REX system offer excellent opportunities for cost-effective learning and testing broader dApp mechanics that can translate back to WAX strategies or inform future PxPortals cross-chain features. Its stability makes it suitable for longer experiments, while the shared Antelope model means your WAX skills transfer immediately. Use it to diversify experimentation without leaving the Antelope family — keep your primary focus, collections, and capital on Pixel Journey and WAX.

### Current EOS Stats (approximate, late June 2026)

- ~$0.06 price, ~$100M market cap
- Strong governance participation
- Improving NFT and DeFi ecosystem

EOS continues to evolve with focus on developer experience and ecosystem growth.

## Getting Started Basics on EOS

1. **Wallet**: Anchor (compatible with Antelope chains) or official EOS wallets. Hardware support available.
2. **Get EOS**: Buy on exchanges, bridge from other chains, or use on-ramps.
3. **Resources**: Use REX to acquire CPU/NET dynamically as needed — more flexible than pure staking.
4. **Explore**: Start with official explorers (eosauthority.com, bloks.io), try dApps, and participate in governance if interested.

**Pixel Journey Tip**: Start small and learn the REX model. Bridge test amounts from WAX. Bring insights back to your core WAX activities. EOS is excellent for broader dApp and governance experimentation that complements (never replaces) your Pixel Journey focus.
