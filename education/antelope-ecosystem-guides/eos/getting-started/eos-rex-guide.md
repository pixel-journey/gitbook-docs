# ⚙️ REX Resource Model on EOS — Flexible Resource Management

**REX (Resource Exchange)** is EOS's innovative system for acquiring CPU and NET resources. Unlike WAX's stake/buy model, REX allows you to rent or lend resources dynamically through a market-like exchange. This provides more flexibility, especially for variable usage patterns.

## How REX Works

- **Lenders**: Stake EOS into REX to earn a share of the rental fees paid by borrowers.
- **Borrowers**: Pay a rental fee (in EOS) to temporarily acquire CPU/NET from the REX pool.
- **Market Dynamics**: Rates fluctuate based on supply and demand. You can rent for short or longer periods.
- **No Permanent Stake Required**: Great for temporary high-resource needs (e.g., during airdrops, voting, or dApp interactions).

## Getting Started with REX

1. Use a compatible wallet like Anchor that has built-in REX support.
2. Go to the REX section in your wallet or via explorers/tools.
3. Decide whether to lend (stake into REX) or borrow (rent resources).
4. Monitor rates and your resource balance.
5. Return borrowed resources when done (or let the rental period expire).

## Safety & Best Practices

- Start with small test amounts when learning REX.
- Understand the rental rates before borrowing large amounts.
- Monitor your resources — running out mid-transaction can still happen if you underestimate needs.
- Use official or trusted tools for REX interactions.
- Combine with standard Antelope security (read transactions, hardware wallet for large holdings, revoke approvals).
