# EOS Getting Started — Mature Antelope for Pixel Journey Explorers

**EOS** is the original mature Antelope blockchain — a high-performance, account-based Layer 1 with a strong developer ecosystem, REX resource exchange, and focus on general dApps, DeFi, and governance. It shares the same DNA as WAX and XPR Network (human-readable accounts, fast finality, resource model), making it familiar territory for Pixel Pioneers.

While WAX is our core home for NFTs, gaming, and the PXJ economy, and XPR offers feeless UX, EOS provides a battle-tested environment for broader experimentation, governance participation, and inspiration for cross-chain strategies via future PxPortals.

## Quick EOS Overview

- **Consensus**: DPoS with fast blocks and finality.
- **Resource Model**: REX (Resource Exchange) for CPU/NET — stake or rent resources dynamically.
- **Accounts**: Human-readable names (like WAX/XPR).
- **Native Token**: EOS — used for staking, governance, and resources.
- **Strengths**: Mature tooling, active developer community, strong governance, improving NFT/DeFi support.
- **Market Context (approx. late June 2026)**: ~$0.06 price, ~$100M market cap, 2.1B total supply.

## Getting Started Basics

1. **Wallet**: Use Anchor (compatible with Antelope chains) or official EOS wallets. Hardware support available.
2. **Get EOS**: Buy on exchanges, bridge from other chains, or use on-ramps.
3. **Resources**: Use REX to acquire CPU/NET as needed — more flexible than pure staking on WAX.
4. **Explore**: Start with official explorers (eosauthority.com, bloks.io), try dApps, and participate in governance if interested.

## Safety First on EOS

- Same Antelope best practices: Read every transaction, start small, verify contracts and URLs.
- Governance voting requires care — understand proposals.
- Bridges and new dApps carry standard smart contract and phishing risks.
- Revoke approvals regularly; use hardware for larger holdings.
- DYOR on any yield or NFT opportunity — EOS has seen its share of projects.

Its maturity offers stability for longer experiments, while the shared Antelope model means your WAX skills transfer immediately.
