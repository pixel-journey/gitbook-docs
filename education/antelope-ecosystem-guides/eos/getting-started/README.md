# 🟠 Getting Started on Vaulta (previously EOS)

> **⚠️ Important Safety Note**  
> Vaulta (the evolution of EOS) is focused on regulated Web3 banking, institutional custody, and secure digital wealth management. Always DYOR thoroughly, start with small amounts when exploring new dApps or tokens, and never invest more than you can afford to lose. Be especially cautious with new or high-value projects.

Vaulta is the rebranded and evolved version of the EOS blockchain, with a strong focus on regulated Web3 banking, institutional asset custody, and secure digital wealth management. It uses the $A token and emphasizes compliance and institutional-grade infrastructure while maintaining the high-performance Antelope foundation.

## Getting Started Safely

### 1. Set Up Your Wallet

**Anchor** is the most compatible wallet for Vaulta. It supports easy network management and hardware integration.

**Recommended Setup**
- Use **Anchor** as your primary wallet for Vaulta.
- Enable hardware wallet integration (Ledger) for larger holdings.
- Add the Vaulta network to your wallet (official RPC details available on the Vaulta website).

### 2. Acquire $A (for gas and activity)

You will need a small amount of the native token (previously EOS, now evolving to $A) for transaction fees and staking. You can acquire it on supported exchanges or bridges.

**Tip**: Start with a very small amount for testing.

### 3. Start Exploring Safely

- Begin with well-established, audited dApps on Vaulta.
- Use trusted explorers to verify transactions and contracts.
- Start with tiny test transactions and positions.
- Revoke token approvals regularly.

### 4. Security Best Practices on Vaulta

- Use hardware wallets for significant holdings.
- Double-check all contract addresses and dApp URLs.
- Be extra cautious of new or high-value projects.
- Never share your seed phrase or private keys.
- Start small and verify everything.
