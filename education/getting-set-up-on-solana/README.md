# Getting Set Up on Solana

Solana is a Layer 1 blockchain built for speed. With block finality under a second and transaction fees averaging a fraction of a cent, it is one of the most active chains for NFTs, gaming, and DeFi — and a natural next frontier for the Pixel Journey ecosystem.

Unlike EVM chains, Solana uses a completely different architecture. Your wallet, your address format, and the tools you use are all distinct from Ethereum and its L2s. This section walks you through everything from scratch.

## What is Solana?

Solana was launched in 2020 by Anatoly Yakovenko. It uses a unique **Proof of History (PoH)** consensus mechanism combined with Proof of Stake, enabling it to process thousands of transactions per second — far more than Ethereum mainnet.

Its native token is **SOL**, used for paying transaction fees and for staking.
