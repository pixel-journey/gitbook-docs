# Wallets on Solana

Solana wallets are separate from EVM wallets. While tools like Phantom support both ecosystems, your Solana address (a base58 string) is entirely different from your EVM `0x...` address — even if you use the same wallet app.

## Which wallet should I use?

| Wallet | Best for | Platform |
|---|---|---|
| **Phantom** | Beginners, multi-chain (Solana + EVM) | Browser + Mobile |
| **Solflare** | Solana-focused power users, staking | Browser + Mobile |
| **Backpack** | xNFT apps, developer-facing features | Browser + Mobile |

All three wallets are **non-custodial** — you hold your own private keys and seed phrase. No company can access your funds.

> **Coming from WAX or EVM?** The biggest adjustment is that your Solana wallet uses a **seed phrase** (12 or 24 random words) as its master backup — not a username/password like WAX Cloud Wallet. Protect this phrase the same way you would protect cash. Anyone who has it has full access to your wallet.
