# 🧪 WaxLabs on WAX

> **⚠️ Important Safety Note**  
> WaxLabs is a development and testing environment. Use it only for testing — never with significant real assets or production keys. Always exercise caution when interacting with any development tools.

WaxLabs is an official development and testing lab provided by the WAX team. It allows developers and advanced users to test smart contracts, transactions, and other WAX interactions in a controlled environment.

## What is WaxLabs?

WaxLabs provides tools for:
- Testing smart contract interactions
- Simulating transactions
- Exploring WAX blockchain features in a developer-friendly interface
- Learning how WAX works under the hood

## Pixel Journey Relevance

While most Pixel Journey users won't need WaxLabs daily, it can be useful if you're interested in:
- Understanding how certain on-chain actions work
- Testing new features before using them on mainnet
- Building or experimenting with custom tools that interact with WAX (including future PxPackages features)

Advanced users and developers in the Pixel Journey community may find it valuable for deeper exploration.

## How to Use WaxLabs Safely

- Only use it with test accounts and small amounts when experimenting.
- Never use production keys or wallets with significant assets.
- Treat it as a learning and testing tool, not a daily driver.
