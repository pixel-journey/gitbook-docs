# EVM Chains

Each EVM chain has its own character, community, fee structure, and native ecosystem — even though they all share the same wallet address and underlying technical standards.

This section has a dedicated page for each chain Pixel Journey is active on. Read the one most relevant to you, or read all of them to understand the landscape before choosing where to focus.

- [Ethereum](ethereum.md) — The original. The highest-security, highest-prestige chain.
- [Base](base.md) — Coinbase's L2. Fast, cheap, and the most beginner-friendly EVM chain.
- [Polygon](polygon.md) — One of the original Ethereum scaling solutions. Huge NFT and gaming ecosystem.
- [Arbitrum](arbitrum.md) — Leading Ethereum L2 for DeFi. Growing NFT scene.
- [Optimism](optimism.md) — Ethereum L2 with a focus on public goods and a strong developer community.
