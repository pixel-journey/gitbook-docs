# Getting Set Up on EVM Chains

Welcome to the **EVM (Ethereum Virtual Machine) Chains** section of the Pixel Journey education hub.

If you've been active on WAX already, this is your next frontier. EVM chains share a common foundation — the Ethereum Virtual Machine — which means one wallet can connect to all of them, and the core concepts (wallets, gas, NFTs, smart contracts) are shared across the whole ecosystem.

## What is EVM?

EVM stands for **Ethereum Virtual Machine**. It's the runtime environment that executes smart contracts on Ethereum, and it has been adopted as a standard by many other blockchains. Every EVM-compatible chain speaks the same technical "language", which means:

- **One wallet works everywhere.** Your MetaMask (or Rabby, Phantom, Coinbase Wallet, etc.) can connect to Ethereum, Base, Polygon, Arbitrum, Optimism, and more — just by switching networks.
- **Your address is the same.** Your `0x...` wallet address is identical across every EVM chain.
- **Smart contracts are portable.** The same NFT standards (ERC-721, ERC-1155) and token standards (ERC-20) are used across all of them.
