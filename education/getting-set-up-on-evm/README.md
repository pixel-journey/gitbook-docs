# Getting Set Up on EVM Chains

**Welcome to the EVM (Ethereum Virtual Machine) section** — the central hub for everything EVM-compatible in the Pixel Journey education hub.

If you've been active on WAX, this is your gateway to the broader Ethereum ecosystem and its high-performance Layer 2s. EVM chains share a common technical foundation, which means:

- One wallet works across all of them
- Your address is the same everywhere
- NFT and token standards are consistent
- Concepts like gas, bridging, and smart contracts transfer directly

This folder is designed to be **smart and non-redundant**:

- **Shared fundamentals** live here in the main EVM hub (gas, addresses, ERC standards, bridging, security, wallets).
- **Specific chain deep-dives** are organized in subfolders (or linked dedicated guides) so you can go deeper into Ethereum, Base, Polygon, BNB Chain, Arbitrum, Optimism, etc. without repeating the common knowledge.

## Why This Structure?

We want the best educational experience:
- Learn the shared EVM basics once (in this hub).
- Then dive into what makes each chain unique (speed, fees, ecosystem, use cases).
- Avoid duplication while still offering clear paths for both beginners and deep explorers.
