# NFT Marketplaces on EVM

Coming from WAX, you will be familiar with marketplace platforms like AtomicHub and NeftyBlocks. The EVM ecosystem has its own set of marketplaces — some generalist, some specialized, and some chain-specific.

Unlike WAX where there are a handful of dominant markets, EVM has several major platforms that compete for volume. As a collector or trader, knowing the differences helps you find the best prices and the lowest fees.

## At a Glance

| Marketplace | Best for | Supported chains | Fees |
|---|---|---|---|
| [OpenSea](opensea.md) | General NFTs, widest selection | ETH, Base, Polygon, Arbitrum, Optimism + more | 0% creator fee (optional), 0.5% protocol |
| [Blur](blur.md) | Pro traders, ETH/Base blue chips | Ethereum, Base | 0% marketplace fee, creator fee optional |
| [Zora](zora.md) | Creator minting, open editions, Base/Optimism | ETH, Base, Optimism, Zora Network | 0.000777 ETH flat per mint |
| [Rarible](https://rarible.com) | Multi-chain, creator focused | ETH, Polygon, Tezos + more | 1% buyer + 1% seller |
| [Atomichub (Polygon)](https://polygon.atomichub.io) | WAX users familiar with AH | Polygon | Familiar AH interface |

## Which marketplace does Pixel Journey use?

Pixel Journey NFTs are listed and tradeable on:

- [OpenSea (Base)](https://opensea.io/collection/pixeljourney-base)
- [OpenSea (Polygon)](https://opensea.io/collection/pixeljourney-polygon)
- [OpenSea (Ethereum)](https://opensea.io/collection/pixeljourney-eth)

OpenSea is the primary marketplace for Pixel Journey EVM NFTs. You will find all active listings there.
