# 🛠️ Antelope Wallets (WAX, XPR, Vaulta/EOS) — Consolidated Guide

**Anchor Wallet** is the primary recommendation for the entire Antelope family. It offers excellent UX, hardware support, and seamless integration with WAX collections, Pixals, and the PXJ economy.

## Primary Recommendation

- **Anchor Wallet** (Desktop + Mobile) — Best overall choice for WAX, XPR, and Vaulta/EOS.
  - Clear transaction previews
  - Built-in resource management (CPU/NET/RAM or REX)
  - Hardware wallet support (Ledger, etc.)
  - Works across all Antelope chains

## Other Options

- Official or community wallets for specific chains when needed.
- Hardware wallets strongly recommended for larger holdings.

## Getting Started with Anchor on Antelope Chains

1. Download Anchor from official sources.
2. Create or import your account (human-readable name on WAX/XPR, account name on Vaulta/EOS).
3. Fund with the native token for resources.
4. Enable hardware wallet integration if desired.
5. Start with small test transactions.

## Safety Best Practices

- Always read transaction details before confirming.
- Use hardware wallets for significant assets.
- Regularly review and revoke permissions.
- Never share seed phrases or private keys.
- Verify all dApps and contracts through official explorers.

## Pixel Journey Relevance

Your WAX Anchor wallet is the central hub for all Pixel Journey activities — collections, staking, crafting, and future PxPortals interactions. Master it first. Skills transfer directly to XPR and Vaulta/EOS for safe experimentation.

**Start small. Use Anchor + hardware where possible. Keep primary focus on Pixel Journey.**
