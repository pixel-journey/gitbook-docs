# 🛠️ Wallets Overview — Consolidated Guide for Pixel Journey Explorers

**Wallets** are your gateway to every blockchain. Different ecosystems use different wallet models, but core security principles remain the same. This consolidated guide helps you choose the right wallet for each chain while maintaining strong security and Pixel Journey best practices.

## Why Consolidated Guides?

Many wallet concepts (hardware support, seed phrase safety, transaction verification, revoke approvals) apply across EVM, Antelope, and Solana. Instead of duplicating content in every chain's subfolder, we maintain single high-quality guides here that each ecosystem can reference.

## Core Wallet Principles (Applies Everywhere)

- **Never share your seed phrase or private keys.**
- **Use hardware wallets (Ledger, Trezor) for anything beyond play money.**
- **Always read transaction details before confirming.**
- **Start small** when trying new dApps or chains.
- **Revoke approvals regularly** (use tools like revoke.cash).
- **Verify URLs and contracts** from official sources.
- **Backup your wallet** securely (metal backups recommended).

## How to Use These Guides

- Start with your **primary chain** (WAX for most Pixel Journey explorers).
- Use the ecosystem-specific guides below for setup and best practices.
- Apply the core principles everywhere.
- Skills transfer: Mastering Anchor on WAX makes EVM and Solana wallets easier.
